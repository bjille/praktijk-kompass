# Praktijk Kompass

Website voor Praktijk Kompass (Ronse) — psychosociale en lichaamsgerichte begeleiding voor mens en gezin, door Griet Avet.

Eén statische pagina (`index.html`), gebaseerd op de visietekst en huisstijl van de praktijk.

## Bekijken

Open `index.html` rechtstreeks in een browser, of host de map als statische site (bv. GitHub Pages).
